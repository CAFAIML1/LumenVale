# Сумісність LumenVale 2.5.0

Основна ціль — **Minecraft Java 1.20.1 / Fabric / OpenGL 4.3+**. Пакет не є Fabric-модом: його інтерфейс надає Iris. Версії Minecraft, Iris та Sodium повинні відповідати одна одній. Оновлювати тільки один мод до довільної версії не слід.

У дев’яти перевірених JAR-файлах нижня межа Fabric Loader у `fabric.mod.json` — `>=0.12.3`. Це декларація Iris, а не підтвердження запуску кожного Loader: інші моди, Sodium і сама версія Minecraft можуть вимагати новішого завантажувача. LumenVale не додає власної жорсткої залежності від номера Fabric Loader. Fabric API не є прямою залежністю шейдерпака.

## Що перевірено

Офіційні JAR-файли звірено за SHA-512. У кожному виконано оригінальний граф включень, сканер опцій, парсери профілів/властивостей і ресурсів для всіх чотирьох профілів. Через оригінальний JCPP пропущено 432 представницькі джерела; 96 унікальних результатів скомпільовано GLSL-компілятором. Об’єкти журналювання та налаштування відлагодження замінено заглушками, оскільки вони залежать від запущеної гри. Класи перевірюваних парсерів не змінювалися.

Це перевірка інтерфейсів і компіляції. Повний рендерер Iris, його перетворення GLSL, розв’язання залежностей Fabric і запуск Minecraft у цій матриці не виконувалися. Усі рядки потребують ігрової перевірки. Опис форм залишається ванільним **1.20.1**; підтримка 1.8.x у парсерах не означає завершену підтримку блоків Minecraft 1.21.x.

## Автоматичний спрощений режим

Воксельне освітлення потребує одночасно `CUSTOM_IMAGES`, `COMPUTE_SHADERS`, `REVERSED_CULLING`, `BLOCK_EMISSION_ATTRIBUTE`. Вони оголошені необов’язковими. Якщо хоча б одного немає, пакет вимикає воксельні ресурси, усі 22 обчислювальні проходи, відбите кольорове світло та фільтрацію скла. Звичайне освітлення блоків, кольорове світло з рук, вода, тіні та ефекти камери залишаються відповідно до профілю. Воксельна перевірка перешкод для світла з рук недоступна. Власне випромінювання моделей установлених блоків не читається з відсутнього `at_midBlock.w`.

Ultra на старому Iris зберігає доступні кінематографічні ефекти, але не має повного воксельного освітлення. Значення перемикача «Воксельне освітлення» може залишатися увімкненим у меню профілю; перевірка можливостей має вищий пріоритет.

На Iris 1.6.x для основної лівої руки ввімкни **Освітлення → Ліва основна рука (Iris 1.6.x)**. Новіші перевірені Iris визначають руку автоматично. OpenGL 4.3 потрібен також спрощеному режиму; це оновлення не додає підтримку OpenGL 3.3, macOS чи OptiFine.

Повні результати й хеші: [iris-matrix.json](iris-matrix.json). Для повідомлення про проблему вкажи Minecraft, Iris, Sodium, Fabric Loader, відеокарту й профіль.
