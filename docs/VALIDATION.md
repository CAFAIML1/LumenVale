# Перевірка LumenVale 2.4.0

Це звіт про виконані перевірки пакета, а не ігровий бенчмарк. Повний запуск нової версії у Minecraft і точні сцени користувача потребують додаткової перевірки.

| Перевірка | Результат |
|---|---|
| Офлайн-компіляція та зв’язування | 552 графічні й 528 обчислювальні конфігурації; 0 помилок |
| Компіляція драйвером NVIDIA | 276 графічних і 264 обчислювальні конфігурації; пройдено |
| Синтетична сцена | 30 варіантів освітлення, вимірів, води й профілів; скінченні HDR-значення, без помилок OpenGL |
| Неповні блоки | Захоплення геометрії плити, килима та сходів; перевірено 40 станів дубових сходів |
| Перешкоди | Порожня половина плити пропускає промінь; зайнята половина та суцільна стіна перекривають його |
| Вибірка поверхні | Освітлений верх плити не засвічує її низ у контрольній сцені |
| Обидві руки | Окремі кольори, додавання двох джерел, основна ліва рука, стіни й забарвлення склом |
| Відбиття | У контрольній кімнаті зникли смуги старої версії, збереглося відбиття світної панелі |
| Iris 1.7.6 | Незмінений парсер директив приймає кольори очищення й таблицю форм RGBA32F 2×1175 |

Нативні GPU-тести виконано на NVIDIA GeForce RTX 4060 Laptop GPU. У тестах парсера Iris залежний від гри хост обходився або замінювався тестовим об’єктом; це не повний запуск Iris у Minecraft.

В Ultra використовується 22 обчислювальні проходи. Сім воксельних полів займають 15 МіБ; таблиця форм — ще 37 600 байтів. Карти тіней, екранні буфери та пам’ять самої гри сюди не входять.

Докладні числові результати: [VALIDATION.json](../VALIDATION.json). Обмеження та способи перевірки ефектів: [README_UA.md](../README_UA.md).
