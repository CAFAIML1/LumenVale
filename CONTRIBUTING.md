# Як долучитися

Для повідомлення про помилку відкрий Issue й укажи версії Minecraft, Iris, Sodium, Fabric Loader і LumenVale, профіль, відеокарту та кроки відтворення. Для візуальної помилки додай скриншот і опиши очікуваний результат. Перед публікацією журналу видали особисті дані й токени.

Для змін коду створи гілку, опиши проблему й спосіб перевірки у pull request. Зберігай сумісність із Minecraft 1.20.1 / Iris 1.7.6 та перевіряй профілі й виміри, яких стосується зміна. Структура пакета та GLSL-компіляція не замінюють перевірку в грі.

Локальні перевірки (Python 3.10+, JDK 21 і glslang у PATH):

```sh
python scripts/validate.py
python scripts/check_compatibility.py --glslang glslangValidator
python scripts/build.py
python scripts/check_repository.py
```

GitHub Actions виконує ці перевірки для push у main і для pull request. Результати містять компіляцію, оригінальні парсери Iris, збірку ZIP, локальні посилання документації та контрольні суми. Наявність зеленого CI не означає запуску Minecraft або перевірки FPS.

Артефакти з dist/ не потрібно комітити. Опубліковані версії в downloads/ оновлюються окремо разом із контрольними сумами й описом змін. Якщо змінився вміст пакета, онови відповідний ZIP перед перевіркою відповідності джерел. Для експериментального випуску з незавершеним ігровим тестом у GitHub Releases потрібно зберігати статус pre-release.

Для галереї використовуй реальні кадри LumenVale. Зберігай оригінал, зазначай версію гри, Iris і шейдерпака, профіль та ресурс-пак, якщо вони відомі. Синтетичні GPU-сцени й згенеровані зображення не слід подавати як знімки Minecraft.
