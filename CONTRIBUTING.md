# Як долучитися

Для повідомлення про помилку відкрий Issue й укажи версії Minecraft, Iris і LumenVale, профіль, відеокарту та кроки відтворення. Для візуальної помилки додай скриншот і опиши очікуваний результат. Перед публікацією журналу видали особисті дані й токени.

Для змін коду створи гілку, опиши проблему й спосіб перевірки у pull request. Зберігай сумісність із Minecraft 1.20.1 / Iris 1.7.6 та перевіряй профілі й виміри, яких стосується зміна. Структура пакета та GLSL-компіляція не замінюють перевірку в грі.

Збірка: python scripts/build.py. Артефакти з dist/ не потрібно комітити. Опубліковані версії в downloads/ оновлюються окремо разом із контрольними сумами й описом змін.
