# Перевірка LumenVale 2.5.0

Це звіт про виконані перевірки пакета, а не ігровий бенчмарк. Повний запуск нової версії у Minecraft і точні сцени користувача потребують додаткової перевірки.

| Перевірка | Результат |
|---|---|
| Офлайн-компіляція та зв’язування | 828 графічних і 792 обчислювальні конфігурації; 0 помилок |
| Компіляція драйвером NVIDIA | 276 графічних і 264 обчислювальні конфігурації; пройдено |
| Синтетична сцена | 30 варіантів освітлення, вимірів, води й профілів; скінченні HDR-значення, без помилок OpenGL |
| Неповні блоки | Захоплення геометрії плити, килима та сходів; перевірено 40 станів дубових сходів |
| Перешкоди | Порожня половина плити пропускає промінь; зайнята половина та суцільна стіна перекривають його |
| Вибірка поверхні | Освітлений верх плити не засвічує її низ у контрольній сцені |
| Обидві руки | Окремі кольори, додавання двох джерел, основна ліва рука, стіни й забарвлення склом |
| Відбиття | У контрольній кімнаті зникли смуги старої версії, збереглося відбиття світної панелі |
| Сумісність Iris | 9 офіційних JAR, 36 конфігурацій профілів, 432 джерела через оригінальний JCPP; [матриця](COMPATIBILITY.md) |
| Спрощений режим | 276 графічних і 264 обчислювальні конфігурації на GPU, відсутні воксельні uniform, ручна ліва рука |
| Iris 1.7.6 | Незмінений парсер директив приймає кольори очищення й таблицю форм RGBA32F 2×1175 |

Нативні GPU-тести виконано на NVIDIA GeForce RTX 4060 Laptop GPU. У тестах парсера Iris залежний від гри хост обходився або замінювався тестовим об’єктом; це не повний запуск Iris у Minecraft.

В Ultra використовується 22 обчислювальні проходи. Сім воксельних полів займають 15 МіБ; таблиця форм — ще 37 600 байтів. Карти тіней, екранні буфери та пам’ять самої гри сюди не входять.

Докладні числові результати: [VALIDATION.json](../VALIDATION.json). Обмеження та способи перевірки ефектів: [README_UA.md](../README_UA.md).

## Оптимізація вибірки

Порівняно GLSL з готового 2.4.0 і поточного 2.5.0 на однакових синтетичних об’ємах. На RTX 4060 Laptop GPU при 960×540, по 24 малювання у запиті таймера, дев’ять вимірів після прогріву: підлога 0.0561 → 0.0280 мс; порожній простір 0.0646 → 0.0279 мс; плита 0.1377 → 0.1355 мс. Максимальна різниця HDR для підлоги 0.006348, середня 0.000436; біля контрольної плити різниці немає. Апаратна інтерполяція має інше округлення, тому всюди побітова тотожність не заявляється. Це вартість окремої функції, а не кадру гри.

## Повторення перевірок

```sh
python scripts/validate.py --glslang /path/to/glslangValidator
python scripts/check_compatibility.py --glslang /path/to/glslangValidator
python scripts/build.py
python scripts/check_repository.py
```

Потрібні Python 3.10+, JDK 21 та glslang. Перша команда перевіряє всі програми й профілі, включно зі спрощеним режимом. Друга завантажує офіційні Iris JAR та бібліотеки тестового хоста, перевіряє хеші й виконує оригінальні парсери; рендерер Minecraft вона не запускає. Завантажені файли й результати зберігаються у `.validation/`, не входять до шейдерпака. Без `--glslang` друга команда перевіряє парсери й препроцесор, а компіляцію явно позначає пропущеною. Нативні GPU-результати цього випуску записано у VALIDATION.json; портативні команди вище не відтворюють GPU-сцену.

GitHub Actions запускає компіляцію, матрицю парсерів і перевірку дистрибутива на Ubuntu для кожного push та pull request. Звіти й зібраний пакет доступні в артефактах запуску протягом семи днів. Це автоматизовані перевірки вихідного коду та інтерфейсів; виконаний CI не додає статусу ігрової перевірки до наведеної матриці.
